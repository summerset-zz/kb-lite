# 06 · 界面：Web UI + 纯 Go 托盘

> **一个 Go 二进制**。UI 是 `//go:embed` 进去的静态资源，用系统浏览器打开；Windows 上同一个进程再挂一个托盘图标。
> 不上 Tauri / Electron（ADR-014）。本文合并了 `GUI-DESIGN.md` 的设计稿，并补齐原稿没覆盖的规格。
>
> **所有 UI 能做的事，CLI 必须也能做**（`docs/05`）。UI 只是 `/api/*` 的一个客户端，不许有自己的业务逻辑。

## 一、为什么不上 Tauri（保留这份论证，别再重新讨论）

| | 浏览器 UI（采用） | Tauri 壳 | Electron |
|---|---|---|---|
| 用户要装什么 | **不需要** | 安装包 + WebView 运行时 | 安装包（自带 Chromium，~150 MB） |
| 包体 | **~11 MB** | ~11 MB + sidecar 11 MB | ~150 MB |
| 一台机器出全部平台产物 | ✅ | ❌ **不能从 Windows 交叉编译出 macOS** | ✅ |
| 托盘 / 开机自启 | 托盘：**纯 Go 自己实现（Windows）** | ✅ | ✅ |
| 签名 | 无 | **Windows 证书 / macOS 公证是真金白银** | 同左 |

三条否决理由，任一条单独成立就够了：

1. **交叉编译断了**：`docs/08` 的「一台 Windows 出五个平台的二进制」是换 Go 换来的最大收益，Tauri 要 Rust 工具链且必须每平台各自构建。
2. **签名**：未签名的 Tauri 包在 Windows 被 SmartScreen 拦、macOS 被 Gatekeeper 拒。本项目不收钱，这笔钱没人出。
3. **它换来的只是托盘**：而托盘在 Windows 上用 `Shell_NotifyIcon` 纯 `syscall` 就能做，**不需要 cgo、不影响交叉编译**。

> 若将来真有 macOS / Linux 托盘需求（`docs/09` 的 v2 条件），再评估 Tauri —— 那时也要先把签名预算定下来。**不是现在。**

## 二、进程形态

一个进程（`kb-lite serve`）同时做：扫描切片、HTTP 服务、托管 UI、托盘（Windows）。**没有 sidecar，没有第二个进程。**

```
kb-lite serve            # 前台进程：监听 + 索引 + 托盘（Windows 上自动挂）
kb-lite serve --open     # 额外打开默认浏览器到 UI
```

- **关闭浏览器标签 ≠ 退出**：daemon 还在跑，托盘图标还在。UI 里要有一行小字说明，并给「退出 kb-lite」按钮。
- **「暂停服务」≠「退出」**（托盘菜单与 UI 都有这两个动作）：
  - 暂停服务 = 关掉 HTTP 监听，**进程、索引、托盘都保留**；再点启动立刻恢复（不重新索引）。对应 `kb-lite stop`。
  - 退出 = 关监听 → 关缓存库 → 进程结束。对应 `kb-lite quit`（`stop` 之后可安全退出）。
- **单实例**：`<配置目录>/lock` 里写 pid + 实际端口。重复双击/重复 `serve` 时：探测 lock 里的端口，能连上就把 UI 打开并退出自己，不再起第二个进程。
- 端口被占自动 `+1`，实际端口写回 `config.json`；UI 一律从 `/api/status` 读，不硬编码。

## 三、技术栈（ADR-016）

| 项 | 选择 | 约束 |
|---|---|---|
| 构建 | **Vite + Vue 3 + TypeScript** | 产物 `web/dist` → `internal/daemon/static/` → `//go:embed`。用户侧永远不需要 Node |
| 样式 | **Tailwind CSS v4** | 设计 token 写在 `web/src/styles/tokens.css`，不引 CSS-in-JS |
| 交互原语 | **Reka UI**（无样式，Radix 系） | 只买「焦点陷阱 / 弹出层定位 / 无障碍」，**不买视觉** |
| 图标 | `@iconify-json/lucide` | 按需引入，不要把整套图标打进产物 |
| 禁止 | SSR / Nuxt / Element Plus / Naive UI / Ant Design | 我们不是后台管理系统，也不要为一个本地工具拖进整套组件生态 |

**硬规则**

- ❌ **禁止 `innerHTML`** 渲染任何来自知识库或用户输入的内容。markdown 预览走「消毒过的渲染器 + 禁原始 HTML」。
- 字符串集中在一个 `strings.ts`（先只做中文），不散落在组件里。
- 所有网络调用收敛到 `api.ts` 一层；组件里不出现裸 `fetch`。

## 四、托盘（Windows）

**图标只有两态：运行中 / 未运行。** 不做「处理中」的第三态 —— Windows 托盘图标频繁重绘观感很差，动画帧更糟；进度属于窗口内的信息。

右键菜单（自上而下）：

```
已在 http://127.0.0.1:7331 运行          ← 可点的普通项：点击 = 复制地址并弹气泡
─────────────────────────────
暂停服务 / 启动服务
正在索引 120 / 530…                      ← 仅索引进中时出现的普通项（点击打开 UI）
设置…                                    ← 打开浏览器到 UI 的设置页
在命令行中打开                            ← 打开 cmd 到该目录并跑一次 kb-lite -h
─────────────────────────────
退出
```

设计约束：

- **不要做灰掉的 disable 项**。地址那一条做成可点复制；索引进度那一条做成可点打开界面。
- 双击托盘 = 打开 UI（不是设置页）。UI 的默认首页就是知识库页，设置是它里面的一页。
- **不弹系统通知**（除「已复制」这类 1 秒气泡）。索引完成不打扰用户。
- 纯 Go 实现要点：隐藏窗口 + 消息循环 + `Shell_NotifyIcon`；只调 `user32` / `shell32`，**不加 cgo**。
  macOS / Linux 暂不提供托盘，用 `kb-lite autostart enable` + `serve --open` 覆盖「开机就要能用」。

## 五、页面

### 5.1 首次启动：向导（只出现一次）

判定条件：`config.json` 不存在，或 `setupCompleted == false`。之后可以在设置页「重新运行向导」。

**第 1 步 · 数据放哪儿**

```
○ 默认位置  <配置目录>/index.db            [推荐]
○ 自定义    [浏览…]
```

说明文字（原话照抄，用户会读这一句）：

> 「这里只存索引缓存。删掉它不会丢失你的任何笔记 —— 重建一下就好。」

**第 2 步 · 端口与访问范围**

```
端口  [7331]  [换一个]
    （像门牌号。被别的软件占了会自动换一个，一般不用管。）

谁可以打开：
  ● 只有这台电脑
  ○ 同一个 WiFi 下的其他设备也能打开
```

选第二项时才出现的红字：

> ⚠️ 打开后，**同一个网络里的人只要知道地址就能看到你的笔记**。我们不推荐。
> 如果你确实需要（比如想用手机上的 AI），我们会自动帮你打开「访问密码」。

**第 3 步 · 第一个知识库 → 开始索引（进度条）→ 完成页**

完成页给出四个**只复制、不下载**的按钮：

| 按钮 | 内容 |
|---|---|
| 复制 curl 示例 | 一条完整可粘贴的命令（含真实端口、按当前 token 设置决定是否带 `Authorization`） |
| 复制给 Agent 的使用说明 | 就是 `/skill.md` 的全文 |
| 复制 MCP 配置 | 能直接存成 `.mcp.json` 的 JSON（指向本地 HTTP endpoint，不是 stdio） |
| 复制整理说明 | 写作 skill（`/authoring.md`）的全文 |

**第 3 步是产品的最后一公里。** 用户卡住的从来不是接口设计，而是「怎么接进我的 agent」。

> 你浏览器里打开的网页不行 —— 它们打不开这个服务。
> 选「同一个 WiFi」时会自动打开，没得关。

**打开时的提示：**

> 把下面这段话发给你的 AI（或它所在工具的配置里）—— 少了它，AI 会连不上：
>
> `我的笔记服务在 http://127.0.0.1:7331 ，访问密码是 a1b2c3…`
>
> （一次性密码，别发给别人；点「换一个」旧的就作废了。）

**管理凭据（用户看不见）**：UI 自己调管理接口用的是另一把 `api-token`，只以 `HttpOnly; SameSite=Strict` cookie 下发，

1. 端口可用（真的 bind 一次再放开）；
2. 目标目录可写（建一个临时文件写完删掉 —— **不能真的建 `index.db`**，Windows 上它正被占用）；
3. 落盘 `config.json`（原子写）；
4. 重新监听；失败则恢复旧端口并报错。

## 六、状态刷新：快照比对，不做 watch

**不引入 inotify / `fsnotify`。** 理由：Windows 下目录多时句柄与 CPU 成本高、跨平台行为不一致，而且增量重建本来只要 64 ms（251 篇实测）。

- 「待更新」= 把当前目录扫一遍 `(relPath, size, mtimeMs)` 与索引记录比对得出的差异数（**不读文件内容、不算 sha1**）。
- 触发时机：打开/刷新页面时；页面可见时每 5 秒一次；用户点「更新」后立刻重扫。
- 从没索引过（daemon 一直没开）时，同一套扫描也能给出「这个 KB 有 128 篇，还没索引」。
- **不做后台自动重建**（那是「后台维护任务」，`docs/00` 明确不做）。要自动，也只在用户点开 UI 时提示。

## 七、外观

- **明暗两套**，跟随系统。**不要用 JS 取系统配色**：`color-scheme: light dark` + `@media (prefers-color-scheme: dark)` 在首帧绘制前就生效，天然不闪。
- 用户手动覆盖时（设置里有「跟随系统 / 浅色 / 深色」），在 `<head>` 里放一小段**同步**脚本读 `localStorage` 并给 `<html data-theme>` —— 同步脚本同样在首帧前执行，也不闪。
- 设计 token：中性色阶 + 一个强调色，圆角 8–12px，字号阶梯 12/14/16/20/24。不要阴影堆叠，靠留白与边框分层。

## 八、文案（假定用户只会用 AI，不懂设计和电脑）

> **这一节的优先级高于「我自己写得爽」。** 字数不够简明就是 bug。

### 8.1 读者模型

写每一句话之前先想这个人：

- 会跟 AI 聊天、会让 AI 帮他改文件，但**不知道什么是端口、接口、token、索引**；大概率也不知道自己的笔记放在哪个盘；
- 他不会读文档，只读屏幕上的字；遇到看不懂的词就点「取消」或直接关掉；
- 他判断「这软件靠不靠谱」全靠**界面说不说人话**。

所以：**不解释原理，只说「会发生什么」和「你现在要做什么」。**

### 8.2 四条规则

1. **一句话只讲一件事**，先说结论再说原因。禁止「因为……（三行）……所以……」。
2. **界面上不出现技术名词**。必须出现时（如日志页），放在「高级 / 给技术人员」里，默认收起。
3. **报错必须给下一步**：发生了什么 + 为什么 + 现在点哪个按钮。只报「失败」等于没做。
4. **不吓人、不卖萌**：不用「！！！」堆情绪，不用「~」和表情包装可爱。担心的部分用**一句具体的后果**说明白就够了。

### 8.3 术语对照（照抄，别自己发挥）

| 界面上写 | 不要写 | 说明 |
|---|---|---|
| 知识库 / 笔记库 | KB、实例、collection | 「KB」只活在 CLI 与 JSON 里 |
| 整理（正在整理…） | 索引、切片、重建、reindex | 动词统一用「整理」 |
| 更新一下 | 重新整理、刷新索引 | |
| 记录文件 | 缓存、index.db、SQLite | 「这里只存我们自己的登记信息」 |
| 有 2 个文件没被收录 | 2 条 skipped / 被跳过 | 点开能看原因 |
| 访问密码 | token、key、Bearer、凭证 | 用户能看懂、能复制的那一把 |
| 同一 WiFi 下的其他设备 | 局域网、0.0.0.0、Host 校验、CORS | |
| 打开地址 / 地址 | URL、endpoint、接口 | |
| 文件开头的设置 | frontmatter、元数据 | |
| 给 AI 的说明书 | skill、prompt、system prompt | |
| 这台电脑上的其他程序 | 本机进程 | |

> 端口这个词保留（界面上一处），但要带一句：「像门牌号，被占了会自动换一个，一般不用管」。

### 8.5 「给 AI 的话」要单独标注

UI 里凡是给 agent 用的内容（curl 示例、skill 全文、MCP 配置）都要在块上方加一行：

## 九、明确不做

- ❌ 在 UI 里编辑 markdown（kb-lite 不做写入；编辑是用户编辑器或 git 的事）
- ❌ 在 UI 里聊天（没有 LLM）
- ❌ git 图形界面（最多在 KB 卡片上显示 git 状态 + 「拉取」，v0.5）
- ❌ 后台自动重建 / 常驻 watch
- ❌ 系统通知打扰（除必要的一次性提示）
- ❌ 中英双语（先只做中文，字符串集中管理，以后再说）

## 十、CLI 平权清单（GUI 能做的，CLI 必须也能做）

| GUI | CLI |
|---|---|
| 添加 / 删除 / 改名 / 启用 / 禁用 KB | `kb-lite add` / `remove` / `rename` / `enable` / `disable` |
| 更新 / 全部更新 | `kb-lite reindex <name>` / `reindex <name> --force` |
| 设置页各项 | `kb-lite settings`（`--port` / `--host` / `--db` / `--token on|off`） |
| 安装两份 skill | `kb-lite skill --install [--target dsh\|claude\|both]` / `kb-lite skill --install-authoring` |
| 启动 / 暂停 / 退出 | `kb-lite serve` / `stop` / `quit` |
| 打开界面 | `kb-lite serve --open` |
| 运行状态 | `kb-lite status [--json]` |
| 自检 | `kb-lite doctor` |

> 这张表是**验收清单**：任何一行缺 CLI 对应物，UI 那一项就不该存在。
