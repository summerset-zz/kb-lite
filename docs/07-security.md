# 07 · 安全边界

kb-lite 把一个**只读**的知识库暴露在 `127.0.0.1` 上。听起来无害，但有两个真实的攻击面，都必须处理。

## 威胁 1：浏览器里的任意网页

任何你访问的网页，其 JS 都可以向 `http://127.0.0.1:7331` 发请求。默认情况下同源策略不允许它**读**响应，但：

- **DNS rebinding** 可以让攻击者的域名解析到 `127.0.0.1`，从而变成「同源」，绕过 CORS；
- 如果本服务发出了 `Access-Control-Allow-Origin: *`，那就等于**公开**了 —— 这正是同类项目踩过的坑。

### 必修项

1. **只绑 `127.0.0.1`**（默认）。`--host 0.0.0.0` 时在终端打印醒目警告，并在 `/api/status` 里标 `"lanExposed": true`，UI 顶部挂一条红色横幅。
2. **校验 `Host` 头**：只接受 `127.0.0.1:<port>`、`localhost:<port>`、`[::1]:<port>`。其余返回 `421 Misdirected Request`。
   这一条是 DNS rebinding 的唯一有效防线（Origin 可以伪造，Host 不行）。
3. **不发任何 CORS 响应头**。需要跨源能力的话，让用户用自己的反向代理加。
4. **校验 `Origin`**：若请求带了 `Origin` 且不等于自身地址，视为跨源 → `403`。同源页面（UI）的 `fetch` 在同源情况下不带 `Origin`（或带同源值），所以不影响自己。
5. **token**：32 字节随机 hex，`0600` 权限，`Authorization: Bearer` 或 `X-KB-Token`。**不允许**「无 token 也能读」的模式。
6. **认证失败节流**：同一来源一分钟内 10 次错误 → `429` + `Retry-After`。成功的请求永不计数。
7. **`Sec-Fetch-Site: cross-site` 的请求直接拒绝**（有该头时）。这是对第 2、4 条的廉价加固。

> 给 UI 用的 token 注入（`<meta name="kb-token">`）是同源页面，不违反上面任何一条；唯一风险是自身 UI 里的 XSS。因此 UI 里**任何用户内容都不得用 `innerHTML` 渲染**，markdown 渲染必须走消毒过的渲染器（禁用原始 HTML）。

## 威胁 2：路径越界

`/kb/{name}/entry/{*path}` 直接接收用户提供的路径。

- 解码后必须 `path.resolve(root, rel)` 再判断**结果是否在 `root` 之内**（比较时先 `realpath` 展开符号链接，再用 `path.relative` 判断不以 `..` 开头）。
- 大小写不敏感文件系统（Windows/macOS）上要按真实大小写比较；Windows 的 **8.3 短名**（`PROGRA~1`）会绕过朴素的字符串前缀检查 —— 用 `realpath` 之后的结果比较，不要比较用户输入。
- 拒绝任何**已存在**的路径解析到 KB 根目录之外的情况（符号链接指向外面也算）。
- 拒绝 `.git/`、`node_modules/`、`.obsidian/` 下的任何路径（即便它们在根目录之内）—— 返回值里不能出现配置文件内容，更不能出现 `.git/config` 里的凭据。

## 不做写入 = 免掉一半风险

- **没有 PUT/POST 内容接口**，没有删除文件的能力。整个服务是只读的。
- 唯一的写操作是**管理接口**（`/api/kbs`），而它只改 `config.json` 与自己的 SQLite，**不碰用户的目录**。
- `DELETE /api/kbs/{name}` 必须只删关联与索引条目。这条要在代码里用测试锁住，而不只是写在文档里。

## 其它

- **不跟随目录软链接**（防遍历环）；文件软链接跟随但受上面「路径越界」约束。
- 单文件 > `maxFileBytes` 跳过；单次 `section` 响应 ≤ 200 KB；`limit` ≤ 10。防止一个请求把内存/上下文打爆。
- **日志里不出现 token**，也不出现完整文件内容（只有路径与长度）。
- `kb-lite token --rotate` 生成新 token 后立即生效，旧 token 失效。
- 版本指纹不要暴露给未认证的请求（`GET /` 返回 UI 是唯一例外，它不含版本信息）。

## 反向代理场景

如果用户想从局域网/外网访问（例如接到手机上的 bot）：

- 默认**不支持**，文档里也不鼓励；
- 若一定要，推荐他自己套 Caddy/Nginx + TLS + Basic Auth，并且 kb-lite 仍然只监听 `127.0.0.1`；
- 不要在代码里实现 TLS、不要实现用户名密码。

## 参照过的清单

以下做法来自 `obsidian-local-rest-api` 的踩坑记录，值得逐条对照：

- 配置目录一律 `403`（按真实落盘路径判断，含短名/大小写/symlink）；
- 认证失败节流；
- 写操作的条件请求（我们没有写操作，直接跳过）；
- 它发的是 `Access-Control-Allow-Origin: *`（因为它要给浏览器插件用）—— **我们不发**。
