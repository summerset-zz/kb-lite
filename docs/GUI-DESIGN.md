# 托盘图标
图标本身的状态：
- 运行中
- 未运行
- 处理中（正在切片等，这个有必要吗？）

右键菜单：
- (已启动时)127.0.0.1:xxxx，不可选（有非系统UI的方法吗？我不想做一个disable的选项）
- 启动服务/暂停服务
- 设置（双击也响应设置，唤起配置窗口）
- 在命令行中打开（用系统命令行打开到文件位置，可考虑自动运行一次help）
- 退出

# 配置窗口(html)

## 首次启动

首次启动时显示配置，包含：
- sqlite文件放在哪儿（输入路径、系统的选择文件夹）。
- 端口设置（带一个检测占用的按钮）
- 连接方式
  - 选择暴露到哪里：localhost？127.0.0.1? 本地IP？（会让局域网其他设备也能用）

保存按钮。保存时再次检测：
- 有没有写那个目录的权限（可以直接把sqlite建了，成功了就说明OK）
- 端口是否被占用

## 知识库配置页
保存之后进入知识库配置页，也是除了首次体验之外的默认首页。
- 知识库列表和对应的文件夹，操作包括：
  - 显示项：
    - 知识库名称
    - 绝对路径
    - 改动情况（进程开着的时候应该有watch来监视改动；如果没开怎么办？通过文件夹的最近更改时间？）
  - 操作项（行尾的下拉列表）
    - 打开文件夹位置
    - 启用/禁用
    - 删除（需确认，不删除文件、但删除切片和知识库）
    - 更新（只处理改动）
    - 全部更新（全部重切）
- 添加目录按钮。默认名称也许可以用path的最后一段？但是可能会造成重复。
- SKILL相关
  - 安装/更新SKILL
  - 给一段指引：如“安装后可以向AI说'安装kb-lite'SKILL”
- 启动/停止按钮
- 当前运行状态区域
  - 运行在哪（哪些IP可以访问）
  - 当前状态
- 设置按钮
  - 转到设置页
- 页脚
  - KBLite vX.XX.XX
  - 作者(Summerset，给github的`summerset-zz`的链接)
  - 反馈问题（去我们仓库的issue页）
  - 检查更新（我们之后做）
  - 支持作者（去作者页）
